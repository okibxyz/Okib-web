# Okib 


## Files

- `index.html`: biography, experience, publications, and contact content.
- `random-lines.html`: Bengali writings with preserved verse line breaks.
- `styles.css`: shared palette, component styling, responsive rules, and motion preferences. Cascade order is intentional.
- `site.js`: shared floating menu, keyboard dismissal, and footer year.
- `app.js`: homepage section tracking, scroll reveals, and the animated greeting.
- `favicon.svg`: PNG and ICO variants are generated by the favicon workflow.



## Publishing

GitHub Pages serves the repository root on `main`. 
When changing CSS or JavaScript, update the asset version query in both HTML files to avoid stale browser caches. Shared page behavior belongs in `site.js`; homepage-only behavior belongs in `app.js`.

## Accessibility and behavior

The floating navigation supports Escape and outside-click dismissal. Motion respects `prefers-reduced-motion`. The portrait orbit lasts 60 seconds; Hello pauses for 5 seconds before deleting. Main headings are 28px on desktop and 24px on phone. Bengali writing is 12px with justified paragraphs.
